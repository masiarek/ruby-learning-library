# Two dots include the end, three dots exclude it

**Level:** 101 · a Python programmer who knows `range` and slices

**One line:** `1..5` is five numbers and `1...5` is four; a Range can be endless (`1..`), beginless (`..5`), made of Strings (`"a".."e"`) or of Floats; and `cover?` asks "between the ends?" where `include?` asks "one of the elements?" — Python's `range` is always half-open, always integers, and a sequence you can index.

A Range is an object with a `begin`, an `end` and an `exclude_end?` flag — it is not a list of its elements, and it stays a Range until something asks it to iterate. That is why `1..` can exist (there is no end to store), why `to_a` on it raises, and why `(1..10**12).sum` returns at once: for Integer ends, `sum` uses the arithmetic-series formula instead of looping *(Not machine-checked here.)*. The same object serves four jobs: slicing (`a[1..2]`, `s[..3]`), `case`/`when` (whose `===` is `cover?`), iteration (`each`, `step`, `map`), and membership. Membership has two spellings that agree on numbers and disagree on Strings: `cover?` compares against the two ends with `<=>`, so `("a".."z").cover?("bb")` is true because `"a" <= "bb" <= "z"`; `include?` walks the elements for a String range, so `("a".."z").include?("bb")` is false — but for a numeric range `include?` is `cover?`, which is how `(1..10).include?(5.5)` is true. A Range is frozen, cannot be indexed, and compares by its ends rather than its elements.

## Reading the output

Rows 1–3: `..` keeps the end and `...` drops it, so the sizes are 5 and 4; a String range runs from `"a"` to `"e"` — it steps with `succ` *(Not machine-checked here.)*.

Rows 4–6: an endless range has `end` `nil` and can still answer `first(3)`; a beginless one answers `include?` and `cover?` by comparing against its one end; asking the endless one for `to_a` is a `RangeError`.

Rows 7–8: `step(3)` and its alias `%` produce every third element (an `Enumerator::ArithmeticSequence`), and a Float range steps by `0.5`.

Rows 9–10 are the two membership questions. On `"a".."z"`, `cover?("bb")` and `=== "bb"` are true and `include?("bb")` is false; on `1..10`, `include?(5.5)` is true because a numeric range answers by comparison, while the same question of the *array* `(1..10).to_a` is false.

Rows 11–13: `when 11..100` matches 42 through `===`; ranges slice arrays and strings, with `..1` and `2..` for the open ends; the two sums come from the formula — the second, `(1..10**12).sum`, would not return in any reasonable time as a loop.

Row 14 is a small trap: `(1...5).last` is `5`, the stored end, even though the end is excluded — `last(1)` and `max` iterate and give `4`.

Rows 15–18: `5..1` is empty rather than descending (`downto` counts down); `1..5` and `1...6` are different Ranges with the same elements; `(1..5)[1]` is a `NoMethodError`; `clamp` takes a range, `cover?` accepts a whole range, and every Range is frozen.

## Compared with Python

The twin asks `range`, `itertools.count` and slices the same eighteen questions. `range(1, 6)` is the only spelling — half-open, integer-only (`range(1.0, 2.0)` is a `TypeError`, row 8), with the step as a third argument (row 7). There are no character ranges (row 3 builds the letters from code points or takes them from `string.ascii_lowercase`), no endless range (`itertools.count` is the endless iterator, row 4, and `list(count(1))` would never return, so row 6 does not run it *(Not machine-checked here.)*), and no beginless range (row 5 is a comparison). Membership in a `range` is integer membership: `5.5` is not in `range(1, 11)` but `5.0` is (row 10), and the two-spellings question of row 9 becomes `in` on a list against a chained comparison. `match` has no range pattern, so row 11 uses guards. `sum(range(...))` iterates, so the twin prints the formula for `10**12` instead of waiting (row 13). Where Ruby's Range refuses indexing, Python's `range` is a full sequence: it has `[-1]`, slices to another `range` (rows 14 and 17), and compares *as a sequence*, so `range(0) == range(1, 1)` is true (row 16) where `(1..5) == (1...6)` was false. `clamp` is `min(max(x, lo), hi)` (row 18).

```ruby
# Kata: compress a sorted list of integers into inclusive ranges, then expand
# the ranges back and check the round trip.

def to_ranges(ints)
  ints.slice_when { |a, b| b != a + 1 }.map { |run| run.first..run.last }
end

def expand(ranges) = ranges.flat_map(&:to_a)

[[1, 2, 3, 5, 7, 8, 9], [4], [], [1, 3, 5], [10, 11, 12, 13]].each do |ints|
  ranges = to_ranges(ints)
  verdict = expand(ranges) == ints ? "round trip ok" : "ROUND TRIP FAILED"
  printf("%-24s -> %-28s %s\n", ints.inspect, ranges.inspect, verdict)
end
```
