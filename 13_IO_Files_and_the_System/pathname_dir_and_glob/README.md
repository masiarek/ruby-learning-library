# `Pathname#/` joins, and `Dir.glob` is sorted

**Level:** 201 · anyone building paths with string concatenation, or reaching for `os.path` habits in Ruby

**One line:** `Pathname` is an object with `/`, `basename`, `extname`, `parent`, `children`, `exist?` and `read`; `Dir.glob` returns its matches sorted (since Ruby 3.0) and understands `**` and `{a,b}`; `File.join`, `File.expand_path` and `File.basename` are the string-level helpers — and `Dir.mktmpdir` removes its directory when the block ends, just as `File.open` closes its file.

Ruby has two levels. The `File` and `Dir` class methods work on Strings: `File.join` joins with one separator however many you gave it, `File.expand_path` resolves `..` against a base, `File.basename`/`extname`/`dirname` split a name, `File.exist?`/`file?`/`directory?`/`ftype` ask the filesystem, and `Dir.glob` (alias `Dir[]`) matches patterns — `*` within a name, `**/` across directories, `{rb,md}` for alternatives — returning the matches *sorted* since Ruby 3.0, and skipping dotfiles unless you pass `File::FNM_DOTMATCH`. `Pathname` (standard library, `require "pathname"`) wraps a String in an object whose `/` (also `+` and `join`) builds a child path, whose `basename`, `extname`, `dirname` and `parent` take it apart, whose `children` lists a directory and whose `exist?`, `read` and `size` ask the filesystem — the same verbs, on an object you can pass around. `relative_path_from` walks up with `..` as needed, `cleanpath` folds `.` and `..` lexically, `descend` and `ascend` enumerate the prefixes. `Dir.mktmpdir` creates a fresh directory and removes it after its block. The program prints only relative names, so the temporary directory's random name — the one thing here that changes on every run — never appears.

## Reading the output

Rows 1–2 are where the program is: the runner starts it inside its `examples/` folder, and `__dir__` is that folder too — the base that `require_relative` resolves against. Rows 3–8 are `Pathname`: `/`, `+` and `join` build `lib/app.rb`; `basename`, `extname`, `dirname` and `parent` (a synonym for `dirname`) take it apart, and `basename(".rb")` strips the extension; the predicates and `read`/`size` ask the filesystem; `children` lists `lib`; and `relative_path_from` produces the `../lib/deep/util.rb` that gets from `spec` to the file. Rows 9–13 are globbing: `**/*.rb` found all three files, in sorted order (`sorted=true` is the point of the title); braces match two extensions in one pattern; `Dir[]` is the same method and `Pathname.glob` returns `Pathname`s; `Dir.children` omits the `.` and `..` that `Dir.entries` includes; and a glob skips dotfiles until asked. Rows 14–17 are the String helpers: `File.join("a/", "/b")` is `a/b` — the separators collapse — `expand_path` resolves `../b` against `/base/a` without touching the disk, `cleanpath` folds `a//b/../c` to `a/c`, and `File.dirname("c.rb")` is `"."`, never empty. Rows 18–21: `sub_ext`, the `absolute?`/`relative?` pair, `each_filename`/`descend`/`ascend`, `File.fnmatch` letting `*` cross a `/` unless `File::FNM_PATHNAME` says otherwise, and `File.ftype`. Row 22 renames, deletes and removes a tree. Rows 23–25 are `Dir.mktmpdir`: without a block it returns a name you must remove yourself (`FileUtils.remove_entry`), with a block the directory exists inside and is gone after.

## Compared with Python

`pathlib.Path` is `Pathname` almost verb for verb: `/` and `joinpath` (row 3); `name`, `suffix`, `parent`, `stem` (row 4 — `stem` is `basename(".rb")`, and there is one `parent` where Ruby has `dirname` and `parent` as synonyms); `exists`, `is_file`, `is_dir` (row 5); `read_text` and `stat().st_size` (row 6); `iterdir` (row 7). `relative_path_from` is `os.path.relpath`, or `Path.relative_to(base, walk_up=True)` — the keyword arrived in 3.12, and without it `relative_to` raises `ValueError` when the target is not inside the base (row 8). `glob.glob` needs `recursive=True` for `**` and promises no order at all, so the twin sorts it (row 9); it has no brace expansion (row 10); `Path.rglob` returns `Path`s (row 11); `os.listdir` never includes `.` and `..` (row 12); `include_hidden=True` is `FNM_DOTMATCH` (row 13). The String helpers differ in their corners: `os.path.join("a/", "/b")` is `/b` — an absolute component restarts the path — where `File.join` gave `a/b` (row 14); `PurePosixPath` keeps the `..` that `cleanpath` folds, so `posixpath.normpath` is the counterpart (row 16); `os.path.splitext("c.tar.gz")` gives a pair, and `os.path.dirname("c.rb")` is `""`, not `"."` (row 17). `fnmatch` lets `*` cross `/` and has no `PATHNAME` flag (row 20), and there is no `ftype` — ask `is_dir()` (row 21). `tempfile.TemporaryDirectory` is `Dir.mktmpdir` with a block and `mkdtemp` is it without one (rows 23–25). The Python library's [Filenames are not text ↗](https://masiarek.github.io/python-learning-library/01_Text_and_Bytes/filenames_are_not_text/index.html) and [What kind of file is this? ↗](https://masiarek.github.io/python-learning-library/01_Text_and_Bytes/what_kind_of_file_is_this/index.html) measure the two things this page skips — the encoding of a filename, and telling a file's kind from its bytes.

```ruby
# Kata: print a directory as an indented tree, directories marked with a
# trailing slash, entries sorted, using Pathname#children recursively.
require "pathname"
require "tmpdir"
require "fileutils"

def tree(path, indent)
  path.children.sort.each do |child|
    puts "#{indent}#{child.basename}#{child.directory? ? "/" : ""}"
    tree(child, indent + "  ") if child.directory?
  end
end

Dir.mktmpdir do |dir|
  Dir.chdir(dir) do
    FileUtils.mkdir_p("lib/deep")
    FileUtils.mkdir_p("spec")
    %w[lib/app.rb lib/deep/util.rb spec/app_spec.rb README.md Rakefile].each { |f| FileUtils.touch(f) }
    puts "./"
    tree(Pathname("."), "  ")
  end
end
```
