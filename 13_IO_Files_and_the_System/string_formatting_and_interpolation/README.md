# `#{}` calls `to_s`; `format` is printf

**Level:** 101 · anyone who knows f-strings and wants the Ruby spellings for the same jobs

**One line:** `"#{expr}"` evaluates any expression and calls `to_s` on the result — only double quotes and their relatives do it — while `format` (alias `sprintf`, and `String#%`) speaks printf: `%05.2f`, `%-10s`, `%x`, `%p` for `inspect`, `%{name}` for a Hash, `%3$s` for positions; Python's f-string is the same idea with the format mini-language after a colon, `!r` for `repr`, and one thing Ruby lacks — a built-in thousands separator.

Interpolation is the everyday tool: inside a double-quoted String, a `%()` literal, a heredoc or a backtick, `#{...}` holds an expression — an arithmetic, a method call, another interpolated String — and its value's `to_s` is spliced in, so `nil` becomes nothing and an Array becomes its `inspect` (that is what `Array#to_s` is). Single quotes keep the characters. The result is always a new String. `format` (`sprintf`, or the `%` operator on a String with an Array or a Hash on the right) is C's printf with additions: `%s` calls `to_s` and `%p` calls `inspect`; a width, a `-` flag, a `+` or space sign flag, a `0` pad and a precision behave as in C; `%b` is binary and `%#x` adds the prefix; `%{name}` and `%<name>d` take a Hash; `%1$s` picks an argument by position; `%*d` takes the width from an argument; and a precision on `%s` truncates. There is no thousands-separator flag — a `gsub` with a lookahead is the idiom. `ljust`, `rjust` and `center` pad by *characters*, which is the text library's [`ljust` and `%-8s` pad by code points ↗](https://masiarek.github.io/ruby-text-learning-library/07_Parsing_and_Formatting/padding_counts_characters/index.html); `<<~` heredocs strip the common indentation, which is its [`<<~` strips indentation ↗](https://masiarek.github.io/ruby-text-learning-library/05_Literals/squiggly_heredoc/index.html) page. Numbers have their own page in this library: [Number formatting](../../15_Numbers/number_formatting/README.md).

## Reading the output

Rows 1–3 are interpolation: double quotes interpolate, single quotes keep `#{x}` literally (its `inspect` shows the `#` escaped), `to_s` is what gets called — `Foo!` from the class's own `to_s`, nothing for `nil`, `[1, 2]` for an Array, `sym` for a Symbol, `{a: 1}` for a Hash — and any expression works, including a String that interpolates on its own. Rows 4–5 are printf's numbers: zero padding, exponent form, the four radixes with `%08b` padded and `%X` upper-case, the sign flags, and width with left-justification. Rows 6–8 are `String#%` with an Array, a lone value, a literal `%%`, `%p` giving `"str"` with quotes and `nil` as the word, and the Hash forms `%{name}` and `%<age>d` (the angle form takes a format, `%<f>.2f`). Row 9 pads with `ljust`/`rjust`/`center` and with `%-10s`/`%10s`. Row 10 converts radixes without `format`: `to_s(2)`, `to_s(16)`, `to_i(16)`, `hex`, and the `#` flag. Row 11 is rounding: `format("%.2f", 2.675)` and `2.675.round(2)` both give `2.68`, while `%.0f` of `2.5` and `3.5` gives `2` and `4`, half to even. The binary double nearest to 2.675 is a hair below it, which is why C's printf and Python round it down; Ruby's `Float#round` and `format` treat the shortest decimal that names the double as the value being rounded. *(Not machine-checked here.)* Row 12: `%g` and `Float#to_s`, which writes `1.0e+20` and `1.0e-05` with a mantissa that always has a decimal point. Rows 13–14: positional arguments, a width from an argument, and a precision that truncates a String. Row 15 is the missing feature: `%,d` is an `ArgumentError`, and the `gsub` idiom inserts the commas. Row 16: `%-6s` and `ljust` count the four characters of `café`, not its five bytes. Row 17: `<<~` removed the two leading spaces and kept the relative indent; `<<-` kept everything. Rows 18–19: `%c` takes an Integer or the first character of a String; `%s` of `3.0` is `3.0`, `%d` truncates `3.99` to `3`, `%f` of an Integer is `3.000000`. Row 20: the interpolated `"#{str}"` is equal to `str` but not the same object.

## Compared with Python

An f-string is `"#{}"` with the format spec after a colon: `f"{x}"` calls `str()` (row 2: `None` prints as the word `None`, where Ruby printed nothing), `f"{x!r}"` calls `repr()` — Ruby's `%p` (row 7) — and since Python 3.12 an f-string may nest quotes of the same kind, so `f'{f"in {x}"}'` works (row 3). Every printf flag in rows 4–5 has a mini-language spelling — `:05.2f`, `:.3e`, `:x :o :b :08b :X`, `:+d`, `: d`, `:5d`, `:<5d` — and the old `%` operator still accepts the C forms (row 6), with a tuple where Ruby takes an Array. `str.format` does named fields from keywords and `{2} {0} {1}` positions (rows 8 and 13), `f"{x=}"` prints the expression and its value (row 8), and a nested `{w}` inside the spec gives a width from a variable (row 13). Radixes are `bin`/`hex`/`oct` and `int(s, 16)` (row 10). Row 11 is the difference to remember: `f"{2.675:.2f}"` and `round(2.675, 2)` give `2.67`, because Python rounds the binary value, which is a hair below 2.675, while `:.0f` of `2.5` and `3.5` gives `2` and `4` just as C does. `str(1e20)` is `1e+20` with no `.0` (row 12). Row 15 is the feature Ruby lacks: `f"{n:,}"` and `f"{n:_}"` insert separators. Padding counts characters here too (row 16), the Python library's [Padding is not alignment ↗](https://masiarek.github.io/python-learning-library/01_Text_and_Bytes/padding_is_not_alignment/index.html) says why that is still not alignment, and [The format mini-language ↗](https://masiarek.github.io/python-learning-library/01_Text_and_Bytes/the_format_mini_language/index.html) is the whole grammar, measured. `textwrap.dedent` is `<<~` (row 17). Row 20 differs: `f"{s}"` of a single `str` can hand back the very same object — a `str` is immutable, so nothing is lost — where Ruby always builds a new String.

## Try it

1. Print an aligned table of items — name left-justified in 10 columns, quantity right-justified in 5, price in 12 with two decimals and a thousands separator (the `gsub` idiom) — and a total line, using `format` only.
2. Write `money(amount, currency: "USD")` that formats `1234.5` as `USD 1,234.50` and `-0.5` as `USD -0.50`, then rewrite it with `String#%` and a Hash (`%<sym>s %<amount>s`) so the two spellings give identical output for five values.

```ruby
# Kata: an aligned table -- names left-justified, quantities right-justified,
# prices with two decimals and a thousands separator, and a total line.
def money(amount)
  whole, cents = format("%.2f", amount).split(".")
  "#{whole.gsub(/\B(?=(\d{3})+(?!\d))/, ",")}.#{cents}"
end

items = [["widget", 3, 4.5], ["gadget", 12, 1234.567], ["gizmo", 1, 0.5]]
puts format("%-10s %5s %12s", "item", "qty", "price")
puts "-" * 29
items.each do |name, qty, price|
  puts format("%-10s %5d %12s", name, qty, money(price))
end
puts "-" * 29
puts format("%-10s %5d %12s", "total", items.sum { |_, q, _| q }, money(items.sum { |_, q, p| q * p }))
```
