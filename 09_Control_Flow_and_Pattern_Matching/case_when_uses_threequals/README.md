# `case`/`when` asks `===`, and every class answers it its own way

**Level:** 201 · a Python programmer who has seen `match` and wonders where the `isinstance` went

**One line:** `case x when y` calls `y === x`, and `===` is an ordinary method: a class answers with `is_a?`, a Range with `cover?`, a Regexp with a match that also sets `$~`, a lambda by calling itself, and any other object with `==` — so one `case` can sort by type, range, pattern and predicate, with no fall-through and a value at the end.

`case` walks its `when` clauses in order and, for each value listed after `when`, asks `value === subject`. That is the whole mechanism; what makes it useful is that `===` is a method each class defines for itself. `Integer === 3` is `3.is_a?(Integer)`; `(1..5) === 3` is `(1..5).cover?(3)`; `/(\d+)/ === "id 42"` runs the match and sets `$~` and `$1`; `->(n) { n > 100 } === 150` calls the lambda; a plain value falls back to `==`, so `when 1` also matches `1.0`. A `when` may list several values, or splat an array into the list. The first match wins and nothing falls through, `then` puts the body on the same line, a `case` with no subject turns each `when` into a plain condition, and the whole thing is an expression: it returns the body's value, `nil` when nothing matched, or the `else` body. The program measures all of it, including a class of our own that defines `===`.

## Reading the output

Rows 1 to 4 are the four kinds of `===` at work: a class (`Integer, Float` is two tests in one `when`), a Range (`1..5`, and the endless `6..` for the rest — and row 2 adds the proof that `Range#===` is `cover?`, not `include?`: `("a".."z") === "bb"` is `true` while `include?` says `false`), a Regexp — which leaves `$~` holding a `MatchData` so the body can read `$1` — and a lambda. Row 5 splats `VOWELS` into the `when`, which is the same as writing `when "a", "e", "i", "o", "u"`. Row 6: `when 1` matched and the later `when Integer`, which would also have matched, never ran; there is no fall-through and no `break`.

Row 7 is the subject-less form: `case` followed directly by `when n < 0` is an `if`/`elsif` chain that reads as a table. Row 8: with no `else`, a `case` that matches nothing is `nil`; with `else`, it is the `else` body. Row 9 is the reason the mechanism is worth knowing: `Even` defines `self.===`, and from then on `when Even` sorts numbers by parity — the same door that `Class`, `Range`, `Regexp` and `Proc` walked through. Row 10: for a plain value `===` is `==`, and `Integer#==` is numeric, so `when 1` matches `1.0`. Row 11: `nil` is matched by `when nil` through `NilClass#===`. Row 12 spells out the four calls behind rows 1 to 4, each answering `true`.

## Compared with Python

Python's `match` (3.10) covers rows 1, 5, 6, 8, 10 and 11 with patterns: a class pattern `int() | float()` is an `isinstance` test with `|` for alternatives (row 1), literals are compared with `==` so `case 1:` matches `1.0` (row 10), `None`, `True` and `False` are compared with `is` (row 11), the first matching `case` wins (row 6), and `case _:` is the `else` (row 8). What Ruby does with a Range, a Regexp or a lambda, Python does with a *guard* — `case int(x) if 1 <= x <= 5:`, `case str() if (m := re.search(...)):`, `case n if n > 100:` (rows 2 to 4) — because a pattern can only be a literal, a name, a class, a sequence or a mapping; there is no protocol like `===` for a value to answer a `case` for itself. The one hook is row 9: a class pattern calls `isinstance`, and `isinstance` honours `__instancecheck__` on a metaclass, so `case Even():` can be taught parity. Row 5 shows why the splat has no counterpart: a bare name in a `case` line *captures* (the next lesson measures it), so a list of allowed values has to be spelled out with `|`. Row 7: `match` needs a subject, so the subject-less table becomes an `if`/`elif` chain. Row 12 is the same four tests written as Python expressions.

# Exercise 1: one classify method using a class, a Range, a Regexp, a lambda
# and a splat in its when clauses, run over a mixed list of inputs.

KEYWORDS = %w[if unless case]

def classify(x)
  case x
  when *KEYWORDS then "keyword"
  when 1..9 then "digit"
  when Integer then "integer"
  when Float then "float"
  when /\A[a-z]+\z/ then "word"
  when ->(v) { v.is_a?(Array) && v.size > 3 } then "long array"
  else "something else"
  end
end

[7, 42, 2.5, 9.5, "case", "ruby", "Ruby", [1, 2, 3, 4], nil].each do |x|
  puts format("%-14s -> %s", x.inspect, classify(x))
end

puts
puts "(1..9) === 2.5 -> #{(1..9) === 2.5}: a Range answers === with cover?, so 2.5 is a \"digit\""
puts "move `when Float` above the Range if that is not what you meant"
