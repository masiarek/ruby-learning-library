# There is more than one way, and one obvious way

**Level:** 101 · a Python programmer's first Ruby afternoon, and the other way round

**One line:** Ruby's idioms — `each`, blocks, `?` and `!` methods, `unless`, `attr_accessor`, `nil`, `Symbol`, mixins, `Comparable`, `Enumerable`, `method_missing`, `Struct`, `Data`, `case/in`, `Rational` — each have a Python twin, printed here on one line each; Ruby keeps several names for one operation where Python keeps one, and `import this` has no Ruby counterpart at all.

Perl's motto was "there is more than one way to do it", and Ruby inherited the attitude: `map` and `collect` give the same result, so do `select` and `filter`, `inject` and `reduce`, `size` and `length`, `then` and `yield_self`. Python's answer, in the Zen it ships as a module, is that "there should be one — and preferably only one — obvious way to do it", and the language mostly keeps that promise: a list has `sort` and nothing else spelled like it. Neither attitude makes the other language's idioms unavailable; it decides which spelling the community reads as native. The table below is the crosswalk this library keeps coming back to, one lesson per row; the program prints one measured line per row, then checks the aliases, then asks Ruby for its Zen (there is none — `require "this"` raises), and ends with a five-line word-frequency program whose output the Python twin reproduces to the byte.

## Reading the output

- **Rows 1–5** are the syntax habits: iteration with a block, filtering and mapping with blocks, a `?` predicate, a `!` method that mutates and hands back its receiver, and `unless` as an expression with a value.
- **Rows 6–11** are the vocabulary: generated accessors, `nil` and its two string forms, `puts` returning `nil` after printing, `require` returning `true` the first time and `false` the second (the file loads once), `Hash` lookups with `nil` for a missing key, and the identity that makes a `Symbol` different from a `String`.
- **Rows 12–15** are the object model: a module mixed in appears in `ancestors`; `Comparable` derives five operators and `between?` from `<=>`; `Enumerable` derives `sort` and `map` from `each`; `method_missing` answers a name that was never defined.
- **Rows 16–19**: the value types — a mutable `Struct`, an immutable `Data` (`with` returns a copy; setting an ivar is a `FrozenError`), pattern matching on an array and a hash, and exact rational arithmetic.
- **Two names, one result**: five pairs of spellings, five equal results. The second line is a finer point: `Method#==` says `then` and `yield_self` are one definition under two names (a true alias), while `map` and `collect` are two separate definitions of the same behaviour — Ruby offers the second name either way.
- **The Zen**: `require "this"` is a `LoadError`. Ruby's design philosophy lives in Matz's talks and books, not in a module. *(Not machine-checked here.)*
- **Word frequency**: `scan`, `tally`, `sort_by` with a two-element key, `first(5)`, `format` — five lines.

## Compared with Python

The twin prints the same nineteen rows. Rows 4 and 8 are where a Python reader most often stumbles in Ruby: Python's `sort()` returns `None` and mutates, while Ruby's `sort!` returns the sorted receiver so it can be chained; `print` and `puts` at least agree on returning nothing. Row 6 needs no declaration — attributes are public by default. Row 9 shows `import` returning a module object and caching it in `sys.modules`, the counterpart of `require`'s `true`/`false`. Row 11 has no symbol type: `sys.intern` gives the identity, an `Enum` gives the fixed vocabulary. Rows 12–15 are the same four ideas under Python's names — a base class in the MRO, `total_ordering`, `__iter__`, `__getattr__`. Rows 16–19 use `namedtuple`, a frozen dataclass (`FrozenInstanceError` on assignment), `match`, and `Fraction`. The one-way check finds none of Ruby's alias names on a list, the Zen prints its twenty-one lines, and the word-frequency program — `Counter`, `re.findall`, `sorted` with a tuple key — prints the same five lines the Ruby program did.

```ruby
# Kata: "more than one way" made concrete - the word-frequency program written
# three ways, with a check that all three agree.

TEXT = "the quick brown fox jumps over the lazy dog the fox sleeps and the dog barks and barks"

def top_five_with_tally(text)
  text.scan(/[a-z']+/).tally.sort_by { |w, c| [-c, w] }.first(5)
end

def top_five_with_each_with_object(text)
  counts = text.scan(/[a-z']+/).each_with_object(Hash.new(0)) { |w, h| h[w] += 1 }
  counts.sort_by { |w, c| [-c, w] }.first(5)
end

def top_five_with_group_by(text)
  text.scan(/[a-z']+/).group_by(&:itself).map { |w, ws| [w, ws.size] }.sort_by { |w, c| [-c, w] }.first(5)
end

results = {
  "tally" => top_five_with_tally(TEXT),
  "each_with_object" => top_five_with_each_with_object(TEXT),
  "group_by" => top_five_with_group_by(TEXT),
}

results.each do |name, pairs|
  puts "#{name}:"
  pairs.each { |w, c| puts format("  %-8s %d", w, c) }
end
puts "all three equal? #{results.values.uniq.size == 1}"
```
